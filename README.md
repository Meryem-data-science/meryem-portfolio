# Portfolio — Meryem El Mustad

Portfolio statique bilingue (français / anglais), sans dépendances de production.

## Aperçu local

Depuis ce dossier :

```powershell
python -m http.server 4173
```

Puis ouvrir `http://127.0.0.1:4173`.

## Structure

- `index.html` : contenu bilingue et structure accessible
- `styles.css` : identité visuelle responsive
- `script.js` : bascule linguistique et animations légères
- `assets/` : portrait professionnel
- `output/pdf/` : CV français et résumé anglais
